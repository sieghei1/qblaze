**QBlaze** — это легкое нативное приложение (Text Expander) для Windows, которое избавляет от рутинного набора одних и тех же сообщений в мессенджерах (Telegram, Discord, WhatsApp), браузерах и CRM-системах. 

Создайте шаблон один раз, задайте короткий триггер (например, `/привет`), и программа мгновенно заменит его на отформатированный текст и прикрепленную картинку в любом окне.

---

## 📥 Скачать и запустить (Установка не требуется)

Программа распространяется в формате портативного исполняемого файла (`QBlaze.exe`) и не требует установки Python или сторонних библиотек:

1. Перейдите в раздел **[Releases](../../releases)** (или скачайте `QBlaze.exe` и `Руководство пользователя.pdf` из репозитория).
2. Положите `QBlaze.exe` в любую удобную папку на компьютере (рядом с файлом автоматически создастся папка `data` с вашей базой шаблонов и картинок).
3. Запустите `QBlaze.exe`.

> **💡 Примечание по запуску:** 
> * Если фильтр Windows SmartScreen при первом запуске покажет окно *«Система Windows защитила ваш компьютер»*, нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
> * Чтобы триггеры срабатывали и внутри программ, запущенных от имени Администратора, запускайте `QBlaze.exe` также от имени Администратора.

## 🚀 Часть 1. Быстрый старт

1. **Создайте шаблон:** нажмите кнопку **`+`** (`Ctrl + N`) в левой панели.
2. **Укажите название и триггер:**
   * *Название:* например, `Приветствие`.
   * *Триггеры:* короткая команда со слешем или точкой, например `/привет, /hi`.
3. **Напишите текст:** оформите текст в редакторе (поддерживаются **жирный**, *курсив*, подчеркнутый, зачеркнутый, `моноширинный код`, цитаты, списки и ссылки).
4. **Прикрепите картинку (по желанию):** выберите файл с диска или нажмите **«Из буфера»** (либо `Ctrl + V` в редакторе) сразу после создания скриншота (`Win + Shift + S`).
5. **Нажмите «Сохранить шаблон» (`Ctrl + S`)**.

**Та-да!** Перейдите в любой чат или браузер, наберите `/привет` — триггер мгновенно сотрется, а на его месте появится ваш готовый ответ.

* **Автораскладка:** даже если вы забыли переключить раскладку и набрали `.ghbdtn` вместо `/привет` — QBlaze поймет вас и вставит шаблон.
* **Вставка мышкой:** двойной клик по любому шаблону в списке сразу вставляет его в последнее активное окно.

## 🔥 Часть 2. Фишки 

### 🧩 Динамические переменные и Спинтакс (кнопка `{ }` на панели)
Используйте умные теги прямо внутри текста шаблона:
* `{date}` и `{time}` — автоматически подставляют текущую дату (`ДД.ММ.ГГГГ`) и время (`ЧЧ:ММ`).
* `{clipboard}` — вставляет текущее содержимое вашего буфера обмена (например, скопированный трек-номер или ссылку).
* `{cursor}` — после вставки шаблона автоматически возвращает текстовый курсор ровно в то место, где стоял тег.
* `{Привет|Здравствуйте|Добрый день}` — **Спинтакс (рандомизатор)**: при каждом срабатывании случайно выбирает один из вариантов, чтобы ответы выглядели живыми.

### 🔍 Глобальный Spotlight-поиск (`Alt + Space`)
Нажмите **`Alt + Space`** поверх любого приложения — в центре экрана плавно появится поисковая строка. Введите 2–3 буквы названия или текста, выберите шаблон стрелками `↑`/`↓` и нажмите **`Enter`** для мгновенной вставки.

### 📌 Компактный режим и закрепление поверх окон
В правом верхнем углу окна находятся кнопки управления видом:
* **Компактный режим** — сжимает программу в узкую вертикальную панель (только список шаблонов и поиск) и закрепляет её поверх всех окон. Удобно расположить сбоку монитора для вставки ответов двойным кликом.
* **Закрепить поверх окон (Булавка)** — фиксирует окно QBlaze поверх остальных программ.

### 📊 Аналитика и автоочистка
QBlaze считает количество срабатываний каждого шаблона. В разделе **«Настройки» → «Аналитика и очистка»** можно посмотреть топ используемых ответов и в 1 клик перенести все неиспользуемые шаблоны (`0 срабатываний`) в папку **«Архив»**.

### 🛡️ Умная защита от коллизий
Если у вас есть триггеры с одинаковым началом (например, `/п` и `/привет`), в мгновенном режиме программа подождет 300 мс после ввода `/п`, позволяя спокойно дописать `/привет`. Также в настройках можно переключить срабатывание триггеров строго по нажатию `Пробела / Enter`.

## ⌨️ Горячие клавиши

| Комбинация | Действие |
| :--- | :--- |
| **`Alt + Q`** *(настраивается)* | Показать / скрыть главное окно QBlaze |
| **`Alt + Space`** | Вызвать плавающий поиск **Spotlight** поверх всех окон |
| **`Ctrl + N`** | Создать новый шаблон или заметку |
| **`Ctrl + S`** | Сохранить текущий шаблон |
| **`Ctrl + F`** | Фокус в строку поиска |
| **`Delete`** | Удалить выбранный шаблон или заметку |
| **`Ctrl + B` / `I` / `U`** | Жирный / Курсив / Подчеркнутый текст |
| **`Ctrl + Shift + X`** | Зачеркнутый текст |
| **`Ctrl + E`** | `Моноширинный код` |
| **`Ctrl + K`** | Вставить или изменить ссылку |
| **`Win + .`** | Системная панель эмодзи |
